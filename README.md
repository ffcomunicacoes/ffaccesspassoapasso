# F&F Access - Central de Ajuda

Versão estática pronta para GitHub Pages.

## Publicação

Envie para a raiz do repositório:

- `index.html`
- `.nojekyll`
- pasta `assets/`

No GitHub: **Settings > Pages > Deploy from a branch > main > /(root)**.

## Administrador

Usuário inicial: `admin`
Senha inicial: `admin123`

O painel permite:

- criar condomínios;
- ativar/desativar funções por condomínio;
- criar novos menus;
- criar, reordenar e excluir etapas;
- adicionar/trocar prints JPG, PNG e WEBP;
- desenhar visualmente a área destacada;
- exportar/importar backup completo, incluindo imagens novas.

## Importante sobre GitHub Pages

GitHub Pages é hospedagem estática. Edições realizadas pelo painel são salvas no navegador (LocalStorage + IndexedDB). Elas não alteram automaticamente os arquivos do repositório.

Use **Backup** para transferir configurações e imagens entre navegadores. Para edição centralizada, visível automaticamente para todos, será necessário um backend/banco de dados.
